# 通せ！われらの要求書　v1.4

架空の病院で、労働組合の人員増要求を通す全3ステージの交渉シューティング。根拠資料を回収し、自動ショットで反論を突破したら、提出口の下から要求書を届けます。

## 遊び方

このフォルダ一式をダウンロードし、`dist/index.html` をブラウザで開きます。ビルドや依存パッケージのインストールは不要です。

| 操作 | PC | スマートフォン |
|---|---|---|
| 前後左右・斜め移動 | 矢印キーまたはWASD | 画面下段の移動パッドを上下左右にスライド |
| 要求書を提出 | Space | パッドの一段上にある「要求書を提出」をタップ |
| 一時停止 | Esc | 「一時停止」をタップ |

各段階の根拠資料は「やさしい」2枚、「ふつう」3枚、「むずかしい」4枚です。難易度が高いほど前後左右に広く散らばります。配置はプレイごとに変わり、好きな順番で全て集めると反論の弱点が開きます。「むずかしい」では、資料回収後に弾の列の隙間が横に動き、後半のステージでは途中で折り返します。被弾しても交渉は続き、評価は被弾回数で決まります。

第1段階では職場アンケートを集め、第2段階では団交休憩のあとに応援配置の対案を検討します。第3段階は理事会の最後の抵抗です。議事録を確認したら、「いつ・誰が・何人」の問いに合わせて、横に流れる弾の壁、両側から絞る弾、二度折り返す弾幕の3波をかわします。緑の枠が次に発射される列の通路を示し、最後の弾が消えると手動で提出できます。会話は理事長の横の吹き出しに表示されます。被弾したときの返しは10種類。団交中は「次のセリフへ」で読み進めます。

## テスト

Node.js のテストランナーで、このフォルダから `node --test tests/engine.test.cjs` を実行します。

`docs/PROTOTYPE-NOTES.md` は試作時点の設計記録です。
