# 通せ！われらの要求書　v1.3

架空の病院で、労働組合の人員増要求を通す全3ステージの交渉シューティング。根拠資料を回収し、自動ショットで反論を突破したら、提出口の下から要求書を届けます。

## 遊び方

このフォルダ一式をダウンロードし、`dist/index.html` をブラウザで開きます。ビルドや依存パッケージのインストールは不要です。

| 操作 | PC | スマートフォン |
|---|---|---|
| 前後左右・斜め移動 | 矢印キーまたはWASD | 画面下段の移動パッドを上下左右にスライド |
| 要求書を提出 | Space | パッドの一段上にある「要求書を提出」をタップ |
| 一時停止 | Esc | 「一時停止」をタップ |

難易度は3種類です。「むずかしい」では、資料回収後に弾の列の隙間が横に動き、後半のステージでは途中で折り返します。被弾しても交渉は続き、評価は被弾回数で決まります。

第1段階では職場アンケートを集め、第2段階では団交休憩のあとに応援配置の対案を検討します。第3段階は「いつ・誰が・何人」の3波を抜けてから提出します。会話は理事長の横の吹き出しに表示されます。被弾したときの返しは10種類。団交中は「次のセリフへ」で読み進めます。

## テスト

Node.js のテストランナーで、このフォルダから `node --test tests/engine.test.cjs` を実行します。

`docs/PROTOTYPE-NOTES.md` は試作時点の設計記録です。
